Utiliser l'API

Le même modèle est accessible en JSON :

POST /api/predire/        {"Time": 0, "V1": -1.36, …, "V28": -0.02, "Amount": 149.62}
GET  /api/exemple/?type=fraude      une vraie transaction du test (fraude | normale | aleatoire)
POST /api/lot/            fichier CSV (champ « fichier ») ou source=test
GET  /api/modele/         fiche du modèle
